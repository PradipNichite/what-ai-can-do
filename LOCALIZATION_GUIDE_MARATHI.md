# Marathi Localization Guide

Marathi localization should sound like a knowledgeable person naturally explaining AI to another Marathi speaker.

Do not translate like a dictionary.

## Core Principle

The goal is understanding, not language purity.

Use natural spoken Marathi with familiar English words where Marathi speakers already use those words.

## Keep Familiar English Words

Generally keep these words in English inside Marathi sentences:

- AI
- Customer Support
- Agent
- Order
- Mobile Number
- Email
- System
- ChatGPT
- API
- Tool
- Website
- Database
- Login
- Ticket
- Dashboard
- Automation
- Report
- Prompt

Do not force awkward Marathi replacements if people would not naturally say them.

Example:

Use:

> AI Agent ला Order System access असेल, तर तो delivery status check करू शकतो.

Avoid:

> कृत्रिम बुद्धिमत्ता प्रतिनिधीला आदेश प्रणाली प्रवेश असेल, तर तो वितरण स्थिती तपासू शकतो.

## Voice

Write for:

- Maharashtra school students.
- College students.
- Parents.
- Small business owners.
- Teachers and coaching class owners.

The language should be:

- Conversational.
- Clear.
- Simple.
- Natural.
- Practical.

It should not feel like Google Translate or textbook Marathi.

## Localize Examples, Not Only Words

Change examples when needed.

Prefer:

- Flipkart or local online shopping instead of only Amazon.
- WhatsApp store instead of generic ecommerce.
- Coaching class, school circular, courier, local shop, payment screenshot, Excel sheet.
- Marathi-English mixed explanation when natural.

## Marathi Quality Checklist

Before finalizing, check:

- Would I actually say this sentence while explaining to someone?
- Did I keep common English words where Marathi speakers naturally use them?
- Did I avoid awkward literal translation?
- Is the sentence simple enough for a student or parent?
- Does the visual still work without heavy reading?
- Does the example feel local to Maharashtra or India?

## Good Style Examples

Natural:

> Customer विचारतो: "माझा Order अजून का आला नाही?"

Natural:

> Support person आधी Order ID किंवा Mobile Number विचारतो. मग तो company System मध्ये order search करतो.

Natural:

> AI कडे System access नसेल, तर तो फक्त general answer देईल. खरा delivery status सांगू शकणार नाही.

Natural:

> AI कडे योग्य Tool आणि Database access असेल, तर तो specific answer देऊ शकतो.

Avoid:

> ग्राहक सहाय्य प्रतिनिधी आदेश ओळख क्रमांक विचारतो.

Avoid:

> संकेतस्थळाधारित माहितीकोशाशी जोडलेला कृत्रिम बुद्धिमत्ता घटक.
