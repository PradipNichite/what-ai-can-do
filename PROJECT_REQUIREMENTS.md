# Project Requirements

## Goal

Create a structured educational project that explains the current state of AI to ordinary people in a simple, visual, practical, and relatable way.

The project should be treated as a multi-format knowledge asset system, not only as a Markdown writing project.

The project should help people understand:

- What AI can already do today.
- How AI can help in daily life, studies, work, business, and society.
- How common jobs and workflows can change when AI is connected to documents, images, tools, or company systems.
- What people should try themselves using tools like ChatGPT.
- What possibilities people are missing because they do not yet know what to ask.

## Audience

The first version should be understandable to:

- 8th to 10th standard students.
- College students.
- Teachers and parents.
- Small business owners.
- Non-technical professionals.
- People who have heard about AI but do not understand practical use cases.

Tone should be simple, grounded, Indian-context-friendly, practical, and honest. Avoid hype and avoid starting from technical architecture.

## Multi-Format Output Model

Each module should have one underlying explanation that can be rendered into multiple native formats:

- Markdown explanation.
- Desktop visual explanation.
- Mobile-first 9:16 visual story.
- Image-only visual version.
- Presentation version.
- Video storyboard.
- Animated video plan.
- Interactive website version.
- Printable PDF.
- Local-language versions.

Each renderer should be designed for its medium. Do not simply convert a Markdown page into images.

## Localization Requirement

Local-language versions should preserve meaning, clarity, and familiarity. They should not be literal translations.

For Marathi, use natural spoken Marathi. Keep familiar English technical words such as AI, Customer Support, Agent, Order, Mobile Number, Email, System, ChatGPT, API, Tool, Website, Database, Login, Ticket, Dashboard, Automation, Report, and Prompt when that is how people naturally speak.

## Phase 1 Acceptance Criteria

- Repo structure is created.
- `README.md`, `PROJECT_REQUIREMENTS.md`, `STYLE_GUIDE.md`, `CONTENT_TEMPLATE.md`, `RESEARCH_GUIDE.md`, and `ROADMAP.md` exist.
- First 5 modules are drafted.
- Each module follows the content template.
- Each module has at least 3 credible sources or research notes.
- Each module has at least 2 image ideas.
- Each module has at least 1 try-it-yourself activity.
- Each module includes Indian context.
- No module reads like a generic AI blog post.
- Content is ready for human review before image generation.
- Multi-format renderer strategy is documented.
- Marathi localization rules are documented.
