# Roadmap

## Phase 1: Foundation

- Create repo structure.
- Add project requirement files.
- Add style guide, content template, and research guide.
- Draft 5 strong modules.
- Add sources, image ideas, and try-it-yourself activities.
- Prepare content for human review.

## Phase 2: Improve the Format

- Review the first 5 modules with students, teachers, and non-technical adults.
- Improve examples and remove confusing sections.
- Create a standardized diagram style.
- Create an image prompt library.
- Create a slide template.
- Create a short video script template.
- Add a basic website output structure.

## Phase 2 Candidate Modules

1. AI for learning English.
2. AI for understanding legal documents.
3. AI for small business WhatsApp replies.
4. AI for teachers creating worksheets.
5. AI for farmers identifying crop issues from photos.
6. AI for shop owners tracking inventory.
7. AI for interview preparation.
8. AI for coding without being a software engineer.
9. AI for creating posters and social media content.
10. AI for comparing products before buying.

## Phase 3: Outputs

- Convert selected modules into classroom slide decks.
- Create 60-second scripts.
- Create 5-minute explainer scripts.
- Create worksheets and discussion activities.
- Build a small static website from the Markdown source.
