# Style Guide

## Writing Principles

- Start from a familiar real-life situation.
- Explain the human workflow before explaining AI.
- Use simple English that an 8th-standard student can follow.
- Keep the Indian context visible: schools, coaching classes, WhatsApp, local shops, parents, tier-2 and tier-3 towns, Hindi, Marathi, and other Indian languages.
- Be practical. Show what the learner can try.
- Be honest about limitations, privacy, safety, and human responsibility.
- Use examples instead of broad claims.

## Avoid

- "AI will change everything."
- "AI is revolutionizing the world."
- Technical-first explanations.
- Silicon Valley-style hype.
- Treating AI as magic.
- Presenting invented examples as real.
- Making every automation sound like job replacement.

## Prefer

Instead of:

> AI agents use LLMs, tools, APIs, and RAG.

Write:

> When your order does not arrive, a support person checks the order system and replies. An AI agent can do a similar thing only if it is connected to the right company system.

## Module Voice

- Short paragraphs.
- Concrete examples.
- Clear step-by-step lists.
- Visual explanation in words before image generation.
- Sources for factual claims.
