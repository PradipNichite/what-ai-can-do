# Visual Journey Template

Use this when a topic should feel like a guided discovery, not a blog post.

## Title

`Topic Name: A Visual Journey`

## Learning Goal

One sentence explaining the single idea the learner should understand by the end.

## How To Use This Module

1. Show the image first.
2. Ask a question.
3. Let learners guess.
4. Reveal one small idea.
5. Move to the next scene.

## Scene Structure

Each scene should have:

- One generated visual.
- One question for the learner.
- One reveal.
- No long explanation.

```markdown
## Scene 1: Familiar Problem

![Scene image](<absolute-or-renderer-safe-path>)

**Ask learners:**
What is happening here?

**Reveal:**
Short explanation in 2-3 lines.
```

## Recommended 5-Scene Flow

1. Familiar problem: start from something the learner already understands.
2. Hidden human workflow: show what people actually do today.
3. Weak AI: show what AI cannot do without context, data, or tools.
4. Capable AI: add the missing access, tool, image, document, or workflow.
5. Human judgment: show where people still matter.

## Design Rules

- One idea per image.
- Big readable text.
- No dense infographic unless the scene is specifically about comparison.
- Use Indian contexts when possible.
- Keep each reveal short.
- Let the learner ask "what changed?" between scenes.
- Save every final image in `assets/images/`.
- Save every prompt in `assets/image-prompts/`.

## End With

- The big idea in one sentence.
- A small comparison table.
- A try-it-yourself prompt.
- A classroom or seminar activity.
- Sources and open questions.
