## Lesson Core

School concept:

```text
Points, axes, distance.
```

AI use:

```text
Embedding spaces and clusters.
```

Mechanism:

```text
item -> numbers -> point in space -> distance -> similarity -> cluster
```

Memory anchor:

```text
Coordinates give ideas an address in AI's meaning space.
```

Keep it distinct from the vectors lesson. Vectors emphasize comparing meaning with number lists and directions; coordinates emphasize placing ideas as points, measuring distance, and seeing clusters.

## Suggested 8-Card Image-Only Sequence

| # | Scene | Learning job | Visible evidence | Motion role |
|---|---|---|---|---|
| 1 | Idea needs a place | AI must organize many ideas | tablet shows scattered idea/icon cards | cards appear |
| 2 | Numbers as address | one item becomes coordinates | icon card transforms into number chips like `(2, 5)` | chips form |
| 3 | Plot the point | numbers place the item | point lands on simple x/y plane | point drops onto grid |
| 4 | Many points | many items get locations | several icons become points | points appear |
| 5 | Distance | nearby means similar | ruler/line between two nearby points | distance line draws |
| 6 | Far apart | far means different | long line to unrelated point | far point dims |
| 7 | Clusters | related ideas form groups | colored clusters on tablet space | cluster rings appear |
| 8 | Quick check | coordinates organize search | query point finds nearest cluster | nearest cluster glows |
