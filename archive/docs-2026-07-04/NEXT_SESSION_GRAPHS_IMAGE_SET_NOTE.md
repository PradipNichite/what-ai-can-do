```text
Recommendations, knowledge graphs, social networks, connected data.
```

```text
entities -> nodes -> relationships -> edges -> connected paths -> recommendation or answer
```

## Suggested 8-Card Image-Only Sequence

| # | Scene | Learning job | Visible evidence | Motion role |
|---|---|---|---|---|
| 1 | Separate items | AI sees many items | tablet shows loose video/topic cards with icons | cards float in |
| 2 | Nodes | each item becomes a point | cards shrink into clear circular nodes | cards transform |
| 3 | Edges | relationships connect nodes | lines connect watched/shared-topic nodes | lines draw |
| 4 | Network | many relationships form a graph | compact graph with clusters | network settles |
| 5 | Nearby nodes | connected items are related | learner's watched node glows near similar nodes | nearby nodes pulse |
| 6 | Path | a connection explains a suggestion | highlighted path from watched topic to suggested topic | path lights up |
| 7 | Knowledge graph | facts can connect too | simple entity graph: concept, use, example icons | fact links appear |
| 8 | Quick check | graphs support decisions through links | two candidate suggestions, connected one chosen | connected choice glows |
