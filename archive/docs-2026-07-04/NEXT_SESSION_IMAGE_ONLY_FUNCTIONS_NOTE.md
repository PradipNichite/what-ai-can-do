## Lesson Core

School concept: function as input -> rule -> output.

AI use: an AI model behaves like a learned function.

Mechanism:

```text
input numbers -> model/function -> transformed numbers -> output scores
```

Memory anchor:

```text
An AI model is a learned function that turns inputs into output scores.
```

## Image-Only Story Plan

Create 8 self-contained 9:16 cards:

1. Familiar school function: input goes into a rule and output comes out.
2. AI model comparison: input goes into a trained model and scores come out.
3. Concrete example: an image or item becomes the input.
4. The input becomes numbers/features.
5. The model transforms those numbers internally.
6. The output is multiple scores, not a magic answer.
7. The highest score becomes the prediction.
8. Quick check: choose the model output by comparing scores.

## Card Requirements

- Use integrated text and visual hierarchy so cards work without voiceover.
- Keep labels short: `input`, `function`, `model`, `scores`, `prediction`.
- Avoid making the model look like a mysterious AI brain.
- Make the score comparison readable on mobile.
- Do not confuse scores with certainty unless explained carefully.
