## Lesson Core

School concept: repeated small steps using slope.

AI use: model training and loss reduction.

Mechanism:

```text
prediction -> loss/error -> gradient direction -> small step -> lower loss -> repeat
```

Memory anchor:

```text
Gradient descent is AI taking small downhill steps on an error curve.
```

## Image-Only Story Plan

Create 8 self-contained 9:16 cards:

1. AI makes a wrong prediction and the card names the mistake.
2. The mistake becomes a visible loss/error score.
3. The loss curve appears, with the current model setting high on the curve.
4. The slope/gradient arrow shows which direction reduces error.
5. The model takes one small update step.
6. The new prediction has lower loss.
7. Repeated small steps move the point toward the low-loss valley.
8. Quick check: small steps learn; too-large steps can overshoot.

## Card Requirements

- Use integrated headline/callout text, not external captions.
- Keep labels short: `prediction`, `loss`, `slope`, `small step`, `lower error`.
- Show the curve and moving point clearly enough for mobile.
- Avoid dense formulas. If using an update expression, keep it simple and large.
- Make the difference between Derivatives and Gradient Descent clear: derivative gives direction; gradient descent repeats the update.
