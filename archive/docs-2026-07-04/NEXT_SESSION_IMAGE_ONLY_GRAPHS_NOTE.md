## Lesson Core

School concept: nodes and edges.

AI use: recommendations, knowledge graphs, social networks, connected data.

Mechanism:

```text
entities -> nodes -> relationships -> edges -> connected paths -> recommendation or answer
```

Memory anchor:

```text
Graphs are math for connected things.
```

## Image-Only Story Plan

Create 8 self-contained 9:16 cards:

1. Lesson opener: Graphs use nodes and edges to help AI connect video topics and recommend the next study video.
2. Each item becomes a node.
3. Relationships become edges.
4. Nodes and edges form a graph/network.
5. Nearby connected nodes show related items.
6. A path explains why one recommendation appears.
7. A knowledge graph connects facts, people, places, or concepts.
8. Quick check: choose the better recommendation by following the graph path.

## Card Requirements

- Use one consistent example, preferably a student video/topic recommendation network.
- Card 1 must name the lesson and orient a new viewer: `Graphs`, `nodes and edges`, `AI recommendations`, and the example task.
- Use ChatGPT/image generation to create each full card as one designed image. Text must be native to the image through tablet UI, notebook panels, poster lettering, sticky notes, arrows, labels, or callouts.
- Do not create a nice study-desk image and paste large caption text on top. Reject anything that feels like a text sticker over a background.
- Keep labels short: `node`, `edge`, `path`, `related`.
- Avoid a dense unreadable network.
- The recommendation must be explained by visible links, not by decorative glow.
- Each card should teach one graph idea without requiring voiceover.
