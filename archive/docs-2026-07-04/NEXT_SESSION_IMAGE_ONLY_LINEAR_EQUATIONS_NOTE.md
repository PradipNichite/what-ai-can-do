## Lesson Core

School concept: variables, coefficients, weighted sum.

AI use: simple model score, neuron-like weighted inputs.

Mechanism:

```text
features x weights -> weighted sum -> score
```

Memory anchor:

```text
Linear equations show how AI can combine many signals into one score.
```

## Image-Only Story Plan

Create 8 self-contained 9:16 cards:

1. A decision uses multiple signals, not one clue.
2. Each signal becomes a feature number.
3. Each feature gets a weight showing importance.
4. Feature times weight creates weighted signals.
5. Weighted signals add into one score.
6. Changing a weight changes the score.
7. The score supports a prediction or ranking.
8. Quick check: which signal should matter more?

## Card Requirements

- Use one concrete example, such as recommending a study video or classifying a simple item.
- Keep labels short: `feature`, `weight`, `score`, `signal`.
- Avoid dense algebra. Show the equation visually as chips and arrows.
- Make multiplication and addition visible without turning the card into a worksheet.
- Keep score comparison readable on mobile.
