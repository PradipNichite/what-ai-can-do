## Lesson Core

School concept: many school math topics work together.

AI use: representation, comparison, prediction, uncertainty, and learning.

Mechanism:

```text
math turns real-world information into numbers, compares those numbers, scores outputs, and improves from error
```

Memory anchor:

```text

```

## Image-Only Story Plan

Create 8 self-contained 9:16 cards:

1. Students already study the math AI uses.
2. Matrices help images become number grids.
3. Vectors help AI compare meaning.
4. Functions turn inputs into outputs.
5. Probability and statistics handle uncertainty and patterns.
6. Linear equations and derivatives help scoring and improvement.
7. Graphs, coordinates, and logic organize relationships, space, and rules.
8. Series map recap: represent, compare, predict, learn.
