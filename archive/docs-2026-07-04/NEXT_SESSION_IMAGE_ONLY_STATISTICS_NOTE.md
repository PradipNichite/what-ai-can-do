## Lesson Core

School concept: mean, spread, trends, examples.

AI use: learning patterns from many examples.

Mechanism:

```text
many examples -> pattern estimate -> variation/noise -> prediction affected by data quality
```

Memory anchor:

```text
Statistics helps AI see patterns across many examples, not just one case.
```

## Image-Only Story Plan

Create 8 self-contained 9:16 cards:

1. One example is not enough to learn a pattern.
2. Many examples create a dataset.
3. Each example becomes a data point.
4. A trend/pattern appears across the points.
5. Variation shows that not every point fits perfectly.
6. AI uses the estimated pattern to predict a new case.
7. Biased or narrow data can create weak predictions.
8. Quick check: which dataset gives a better pattern?

## Card Requirements

- Use readable dots, trend lines, and simple labels.
- Keep labels short: `examples`, `data points`, `trend`, `variation`, `data quality`.
- Avoid a dense statistics textbook page.
- The lesson must show why many examples matter.
- The final card should make data quality visually obvious.
