## Lesson Core

School concept:

```text
True/false, conditions, if-then reasoning.
```

AI use:

```text
Decision trees, filters, agents, safety rules.
```

Mechanism:

```text
condition -> true/false check -> branch -> next rule -> decision
```

Memory anchor:

```text
Logic helps AI follow rules instead of only guessing.
```

Use one relatable example consistently. Recommended example:

```text
AI study helper choosing whether to answer, ask for more context, or refuse unsafe cheating.
```

This keeps the topic student-centered and avoids making logic feel like abstract programming only.

## Suggested 8-Card Image-Only Sequence

| # | Scene | Learning job | Visible evidence | Motion role |
|---|---|---|---|---|
| 1 | Request arrives | AI receives a task | student tablet shows a request card with icon-only homework context | request card appears |
| 2 | First condition | AI checks one rule | condition diamond splits into yes/no | diamond lights up |
| 3 | True/false branch | different answers follow different paths | green path and red path separate | branches draw |
| 4 | Decision tree | multiple rules form a tree | compact tree with 3 decisions | tree grows |
| 5 | Filter | rule blocks unsafe/bad option | blocked path fades, safe path remains | blocked path dims |
| 6 | Agent action | rules choose next step | options: answer, ask context, verify | chosen action glows |
| 7 | Logic plus scores | rules combine with learned confidence | score bars pass through rule gate | gate opens |
| 8 | Quick check | logic is rule-following | simple if-then path reaches final decision | final checkmark appears |
