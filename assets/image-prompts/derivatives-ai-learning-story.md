# Derivatives AI Learning Native Story Prompts

Topic: Derivatives: How AI Learns From Mistakes.

Format: 9:16 native mobile-first visual story for 11th/12th standard students.

Key direction:

Explain derivatives through intuition first, then touch the actual mathematical mechanism. Use mistake, direction, small adjustment, repeated improvement, tangent slope, tiny input/output changes, error curve, and one simple update rule.
