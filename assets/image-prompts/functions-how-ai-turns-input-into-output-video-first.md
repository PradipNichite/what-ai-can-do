# Functions: How AI Turns Input Into Output - Video-First Prompt Pack

These prompts are for source frames intended to become image-to-video clips. The goal is not only attractive images; each frame must visibly teach one technical step.

Series: How AI Uses Math
Source module: `modules/visual-ai-concepts/functions-how-ai-turns-input-into-output.source.md`
Output image folder: `assets/images/functions-how-ai-turns-input-into-output-video-first/`

## Style Bible

- warm modern Indian educational illustration
- 9:16 vertical mobile frame
- recurring Indian teenage learner with dark wavy hair, teal/green shirt
- wooden study desk, warm desk lamp, notebook, pen, books, small plant
- tablet as the main technical surface
- clean technical overlays: function arrows, number chips, feature chips, model layers, score bars
- minimal embedded text, but key numbers and short labels must be readable
- no logos, no watermark
- avoid flat white diagram cards detached from the study environment
