# Gradient Descent Frame 4 Style Grid

Source module: `modules/visual-ai-concepts/gradient-descent-how-ai-learns-from-mistakes.source.md`
Purpose: generate one controlled technical frame in multiple visual styles to decide which style best matches the video lesson vision.
Output folder: `assets/images/experiments/gradient-descent-frame4-style-grid-v1/`

Learning job for every style: local slope gives a direction clue; gradient descent updates the model in the opposite direction to lower error.

Fixed technical content for every style:

- One U-shaped loss curve.
- One point on the slope.
- One tangent or slope cue pointing toward higher loss.
- One separate downhill update arrow moving opposite the gradient toward lower error.
- Required labels only: "gradient: higher loss", "move opposite", "lower error".
