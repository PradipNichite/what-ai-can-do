## Goal

Create a paused visual story that explains graphs without voiceover, animation, or external captions.

Self-contained opener requirement:

The first card must not assume the viewer knows the title or project context. It must name the lesson topic, connect the school concept to the AI use, and introduce the video recommendation example used by the rest of the story.

Native generation requirement:

Use image generation to create the full educational composition. Do not treat the image as a background and the text as a later overlay. Text should be part of the scene through tablet UI, notebook panels, poster typography, sticky notes, arrows, labels, and mini cards.

Core mechanism:

```text
entities -> nodes -> relationships -> edges -> connected paths -> recommendation or answer
```

Memory anchor:

```text
Graphs are math for connected things.
```

## Character / Style Bible

- realistic warm study-desk/tablet technical style
- 9:16 vertical mobile frame
- recurring Indian 11th/12th standard learner with dark wavy hair and teal/green shirt
- wooden study desk, warm desk lamp, notebook, pen, books, small plant
- tablet as the main technical surface
- one consistent example: a student video/topic recommendation network
- large readable technical overlays: video cards, nodes, edges, connected path, recommendation choice
- integrated generated headline/callout text on each card, not external captions or pasted text stickers
- short labels only: `node`, `edge`, `path`, `related`
- no dense unreadable network, no generic glowing AI art, no logos, no watermark
