## Character / Style Bible

Recurring learner:

- Indian 11th/12th standard student
- dark wavy hair
- teal/green shirt
- curious, focused, thoughtful expression
- seated at a wooden study desk with notebook, pen, books, small plant, warm desk lamp
- tablet as the main technical surface
- cozy study-room background
- realistic warm educational image style, polished, mobile-first, 9:16 vertical

Visual rules:

- Use the current Direction B math-series style from Functions, Statistics, Linear Equations, and Series Intro.
- Keep the tablet overlays readable in a 9:16 mobile frame.
- Show nodes, edges, paths, clusters, and arrows as large visual elements.
- Use one consistent example: a video recommendation network.
- Use minimal embedded text. Preferred labels, if needed: `node`, `edge`, `path`.
- Avoid a huge unreadable network, generic glowing AI art, logos, watermarks, and dense graph theory vocabulary.

## Per-Frame Risk Notes

- Frame 1: Keep cards separate and icon-based so the transformation into nodes is obvious.
- Frame 2: The `node` label must stay small and stable; the node itself must carry the meaning.
- Frame 3: The `edge` label should not replace visible connection lines.
- Frame 4: Limit the graph to about 10 nodes so it remains readable in mobile framing.
- Frame 5: Use visible edges to explain relatedness; avoid unsupported glow.
- Frame 6: The path should be a short, easy-to-follow route with a clear start and end.
- Frame 7: Keep the knowledge graph icon-based and sparse; avoid dense concept-map text.
- Frame 8: The quick-check answer must be justified by a visible path, not just a check mark.
