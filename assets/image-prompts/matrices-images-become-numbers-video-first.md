# Matrices: How Images Become Numbers - Video-First Prompt Pack

These prompts are for source frames intended to become image-to-video clips. They are not static poster cards. Keep embedded text minimal because captions and voiceover will carry the explanation.

## Character / Style Bible

Recurring learner:

- Indian 11th/12th standard student
- curious, calm, thoughtful
- dark hair, simple school/casual outfit
- recurring study desk and smartphone
- warm modern Indian educational illustration
- clean, polished, mobile-first, 9:16 vertical

Visual rule:

- One visual action per frame.
- Minimal or no embedded text.
- Large subjects and clear motion targets.
- Avoid dense tables except the one matrix glimpse.
