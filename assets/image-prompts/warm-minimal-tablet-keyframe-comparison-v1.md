# Warm Minimal Tablet Keyframe Comparison v1

Purpose: regenerate representative key frames from existing lessons in the Warm Minimal Tablet Closeup style, then compare against the current lesson styles before deciding whether to regenerate full lessons.

Output folder: `assets/images/experiments/warm-minimal-tablet-keyframe-comparison-v1/`

Style rule for every frame:

- 9:16 vertical video-first source frame.
- Warm study-desk/tablet closeup with human context through hands, sleeve, partial face, or soft desk environment.
- Tablet is the main technical surface and fills most of the frame.
- Sparse native text only; voiceover carries explanation.
- One clear motion target for later Runway image-to-video.
- No generic slide layouts, no large poster headlines, no logos, no watermark.
