# Prompt-Based Content Designer

Status: Backlog idea.

Parent topic: [AI-Era Careers And Work](../topics/ai-era-careers-and-work.md)

## Core Hook

Prompts can help create story cards, product visuals, ad concepts, explainer images, and video scenes.

## Target Learner

Creators, students, marketers, teachers, and designers.

## Why It Matters

This is a new creative workflow, but it still needs taste, revision, and visual QA.

## Possible 9:16 Visual Story

1. Person has a rough idea.
2. Prompt turns it into a visual direction.
3. Image generation creates options.
4. Human reviews text, accuracy, tone, and layout.
5. Final card becomes shareable content.
